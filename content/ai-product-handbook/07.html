      07.1

      AI, machine learning, deep learning, foundation model

      Bốn tầng lồng nhau, từ khái niệm rộng nhất tới loại model các sản phẩm hiện nay hay dùng.

      Machine learning có ba kiểu học chính. Supervised learning học từ dữ liệu đã gán nhãn (biết trước đáp án). Unsupervised learning tự tìm cấu trúc ẩn trong dữ liệu chưa gán nhãn. Reinforcement learning tối ưu hành vi bằng thưởng, phạt khi tương tác với môi trường. LLM thuộc nhóm foundation model: được huấn luyện trước trên dữ liệu khổng lồ, rồi dùng lại cho nhiều tác vụ.

      07.2

      Token, embedding và context window

      Token là đơn vị tính tiền và giới hạn; embedding là cách máy “hiểu” nghĩa; context window là mặt bàn làm việc.

      Tokenization chia văn bản thành token: một từ, một phần của từ hoặc một ký tự. LLM tính chi phí và giới hạn đầu vào, đầu ra theo số token, nên số token ảnh hưởng trực tiếp tới tiền API và latency. Với tiếng Anh, khoảng 1.000 token tương đương 750 từ; tiếng Việt thường tốn nhiều token hơn cho cùng lượng chữ.

      Embedding chuyển văn bản thành vector số nhiều chiều; các đoạn gần nghĩa nằm gần nhau. Vector database lưu các vector này để tìm kiếm theo nghĩa (semantic search) thay vì khớp từ khóa.

      Context window là số token tối đa model nhận và xử lý trong một lần gọi, tính cả prompt và câu trả lời. Quản lý bộ nhớ hội thoại và sắp xếp nội dung trong context window là việc kỹ thuật quan trọng để model không “quên” ngữ cảnh trong tương tác dài.

      Ghi nhớToken là đơn vị tiền tệ của LLM. Quản lý token là quản lý chi phí sản phẩm.
      07.3

      Prompt engineering và context engineering

      Điều khiển đầu ra của model bằng lời dặn và dữ liệu đưa vào, không đụng tới trọng số.

      • System prompt và vai trò. Chỉ thị nền: vai trò, văn phong, và các quy tắc cấm model làm những điều không mong muốn.
      • Few-shot prompting. Đưa một vài ví dụ đầu vào – đầu ra ngay trong prompt để định hình cấu trúc và định dạng.
      • Context injection. Chèn thêm thông tin động (dữ liệu người dùng, tài liệu tra cứu) vào prompt trước khi gửi, giúp giảm hallucination.

      Context engineering mở rộng ý cuối: không chỉ viết câu lệnh hay, mà chọn đúng thông tin nào được đưa vào context window, theo thứ tự nào, cắt bớt cái gì. Với sản phẩm thật, phần này thường quyết định chất lượng nhiều hơn câu chữ của prompt.

      07.4

      RAG, fine-tuning, tool calling, agent

      RAG khi tri thức thay đổi và cần trích nguồn; fine-tuning khi cần cố định định dạng hoặc văn phong.

      Bên cạnh hai hướng trên có thêm hai mẫu kiến trúc. Tool calling (function calling) cho model quyết định gọi API bên ngoài để làm việc thật: truy vấn SQL, gửi email, tạo hóa đơn. AI agent và model routing: hệ thống tự điều hướng từng tác vụ tới model phù hợp, dùng model nhỏ, rẻ cho việc đơn giản và chỉ chuyển sang model lớn khi cần suy luận phức tạp.
